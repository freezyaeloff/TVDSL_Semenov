# HW1. От регулярных выражений к минимизированному ДКА

Лексер языка Funny на Python, без сторонних библиотек и без `re`.

## Запуск

Из папки `hw1` (Python 3.10 или новее):

```console
python funny_lexer.py --out dfa.json --tests
```

Если интерпретатор доступен как `python3` или `py`, заменить `python` на соответствующую команду. Проверено на Python 3.14.5.

Команда сохраняет минимальный автомат в `dfa.json`, исходный ДКА в `dfa_before.json`, результаты тестов в `tests.md`. С `--tests` таблица `input / expected / actual / ok / note` также выводится в консоль. Без `--tests` создаются только таблицы автоматов. Путь `--out` задаётся относительно текущего каталога; его родительская папка должна существовать. Дополнительные файлы сохраняются рядом с ним.

Файлы:

- `funny_lexer.py` — AST, Томпсон, subset construction, Хопкрофт, исполнение и CLI.
- `test_lexer.py` — корпус тестов и проверки алгоритмов. Можно запустить отдельно: `python test_lexer.py`.
- `dfa_before.json`, `dfa.json` — полные таблицы переходов до и после минимизации.
- `tests.md` — сгенерированный отчёт с expected/actual для каждой строки.

## Как устроено

1. Регулярные выражения задаются AST прямо в коде. Есть `char`, `char_class` (узел `class`), `cat`, `alt`, `star`, `plus`, `opt`. `cat()` обозначает ε, `alt()` — пустой язык. `literal()` собирает строку в конкатенацию символов. Парсер текстовых регулярок заданием не требуется.
2. `build(node, nfa)` строит фрагмент Томпсона с одним входом и выходом. `None` обозначает ε-переход. У комбинированного НКА общий старт и ε-переход в каждое правило. Конечные состояния хранят индекс правила.
3. `subset_construction()` обходит подмножества НКА в BFS. ε-замыкание берётся в начале и после каждого `move`. При нескольких принимающих состояниях выбирается минимальный индекс правила. Пустое подмножество становится явной ловушкой **до минимизации**.
4. `minimize()` выполняет алгоритм Хопкрофта. Начальные блоки разделены по `(имя токена, skip)` и непринимающим состояниям. Обратные переходы позволяют находить прообраз разделителя. Если разделённый блок уже ожидает обработки, обрабатываются обе части, иначе добавляется только меньшая. Для фиксированного ASCII стандартная оценка алгоритма — O(n log n); здесь используются обычные Python-множества.
5. `run_dfa()` идёт до ловушки или конца ввода и запоминает последний приём (maximal munch). Возвращается имя первого токена или `None`, включая WS/COMMENT, как в тестах задания. Метка `skip` сохраняется в таблицах автоматов.

Порядок 16 правил: WS, COMMENT, FUNCTION, RETURNS, USES, WHILE, IF, ELSE, TRUE, FALSE, NOT, AND, OR, IDENT, INT, OP. Поэтому `function` — FUNCTION, а `functionx` — IDENT. `00` разбирается как INT("0"), INT("0"); `===` — OP("=="), OP("=").

Алфавит — 128 символов ASCII. В каждом состоянии определены все 128 переходов. Символы вне ASCII функция `step()` отправляет в ловушку. В комментарии допустим любой ASCII, кроме `\n`, поэтому `@`, `\r` и даже `\x00` внутри комментария разрешены спецификацией, а `π` — нет.

## Использование из Python

```python
from funny_lexer import build_funny, run_dfa

_, _, dfa = build_funny()
print(run_dfa(dfa, "function"))  # FUNCTION
print(run_dfa(dfa, "01"))        # INT
print(run_dfa(dfa, "==="))       # OP
print(run_dfa(dfa, "π"))         # None
print(run_dfa(dfa, "1π"))        # INT
```

В консоли и `tests.md` результат — имя первого токена или `None`.

## Формат таблиц

Поля: `start`, `trap`, `n_states`, `accept`, `trans`. В `accept` метка имеет вид `["IDENT", false]`. Ключ перехода — номер состояния, `|`, затем ровно один символ, например `"0|f"`. Управляющие символы экранированы средствами JSON.

Проверено:

- Эквивалентность результатов ДКА до и после минимизации на корпусе тестов, как требуется в задании.

### Уточнения к презентации

- `0|[1-9][0-9]*|00*` не эквивалентно `0|[1-9][0-9]*`: первое дополнительно принимает `00`, `000` и т. д. Реализовано исходное правило INT.
- При maximal munch и `=|==`, и `==|=` дают один токен `==`. Порядок правил важен только при равной длине; порядок альтернатив внутри OP этого не меняет.
- Запись операторов на слайде трактуется как перечень буквальных операторов: круглые/квадратные/фигурные скобки тоже являются токенами OP.
- Non-ASCII не входит в таблицу из 128 символов: для него предусмотрен явный переход в ловушку в исполнителе.
